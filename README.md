# EoingTalk Releases

EoingTalk 공식 공개 배포 저장소입니다. 일반 사용자는 **한국어 Windows 설치형(EXE)** 사용을 권장합니다.

## 최신 설치본

- Windows 설치형: `releases/latest/download/EoingTalk-Setup-current.exe`
- 포터블 ZIP: `releases/latest/download/EoingTalk-current.zip`

설치형은 사용자별 고정 경로에 설치되고 Windows 로그인 자동 실행을 등록합니다. EoingTalk 설정, 라이선스, 추가 카카오톡 프로필은 `%LOCALAPPDATA%\EoingTalk`에 별도 보존됩니다.

## Public Runtime Files

- `releases/latest/download/latest.json`: update manifest
- `releases/latest/download/plans.json`: plan manifest
- `releases/latest/download/EoingTalk-current.zip`: portable package
- `releases/latest/download/EoingTalk-Setup-current.exe`: Korean Windows installer
- `ads/ads.json`: free-edition ad campaign manifest

애플리케이션 소스 코드는 별도 private source repository에서 관리합니다.
